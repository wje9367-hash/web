[규제 업데이트 요청]

아래 내용을 antigravity 웹앱(web/src/App.tsx)에 반영해줘.
반영 전에 반드시 다음 체크리스트를 순서대로 실행할 것:

─ 체크리스트 ─
1. CELEX 번호로 EUR-Lex 직접 접근 확인 (404 방지)
2. 시행일(enforcement date) vs 의무 적용일(application date) 구분
3. EU_PACKAGING_REGS 객체에 새 키 추가
4. UI 카드 추가 (기존 BPA/PFAS 카드 색상·구조 참고)
5. documents 배열에 제출 서류 항목 추가
6. complianceData 해당 국가 banned 필드 업데이트
7. npx tsc --noEmit 로 TS 에러 확인

─ 현재 앱에 이미 등록된 EU 규제 (중복 추가 금지) ─
- PPWR (EU) 2025/40 — CELEX:32025R0040
- PFAS FCM (EU) 2025/40 Art.5
- BPA FCM (EU) 2023/2468 — CELEX:32023R2468, 시행 2026.07.20
- SUP (EU) 2019/904 — CELEX:32019L0904
- FCM Framework (EC) 1935/2004 — CELEX:32004R1935

[정기 규제 모니터링 알림]

antigravity 웹앱의 식품 법규 데이터를 최신 상태로 유지하기 위한 정기 점검 시간입니다.

─ 이번 주기에 확인해야 할 소스 ─

□ EUR-Lex — EU FCM 규정 신규 발행 확인
  검색: site:eur-lex.europa.eu "food contact" 2025 OR 2026
  주요 대상: Regulation (EU) No 10/2011 개정, 1935/2004 위임규정

□ EFSA Scientific Opinions
  URL: efsa.europa.eu/en/publications
  확인: 최근 6개월 내 식품 접촉재·식품 첨가물 관련 새 의견서

□ DG SANTE (EU 식품안전총국)
  URL: food.ec.europa.eu/safety/food-contact-materials_en
  확인: 신규 공지·입법 예고

□ 식약처 수입식품 해외규제 정보
  URL: mfds.go.kr 또는 impfood.mfds.go.kr
  확인: 최근 분기 해외 규제 변경 현황

─ 현재 앱에 등록된 규제 (이미 있는 것은 생략) ─
- PPWR (EU) 2025/40 — CELEX:32025R0040
- PFAS FCM (EU) 2025/40 Art.5
- BPA FCM (EU) 2023/2468 — 시행 2026.07.20
- SUP (EU) 2019/904 — CELEX:32019L0904
- FCM Framework (EC) 1935/2004

새로 확인된 규제가 있으면 알려줘. 바로 버전 A 체크리스트로 반영할게.
없으면 "이번 주기 신규 규제 없음"으로 마무리해도 돼.


================================================================
  Claude Desktop Scheduled Task 설정 팁
================================================================

1. Claude Desktop > Settings > Scheduled Tasks (또는 동등 메뉴)
2. 새 작업 추가:
   - 이름: "식품 법규 정기 점검"
   - 주기: 매월 1일 / 분기 첫째 날
   - 내용: 버전 B 전체 텍스트 붙여넣기
   - 작업 경로(선택): antigravity 프로젝트 폴더

새 규제가 발견되면 Claude가 버전 A 체크리스트를 자동 적용해서
App.tsx에 직접 반영합니다.
